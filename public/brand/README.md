# لوگوی مدفیکس

لوگو از حالت رستر به وکتور تبدیل شده و سپس در ابعاد **4096×4096** رندر شده است؛ بنابراین لبه‌ها تیز و بدون پیکسل‌شدگی هستند.

## فایل‌ها

| فایل | توضیح |
| --- | --- |
| `madfix-logo-white-4096.png` | پس‌زمینه سفید، لوگو با رنگ‌های اصلی (سرمه‌ای و نارنجی) |
| `madfix-logo-black-4096.png` | پس‌زمینه مشکی، بخش سرمه‌ای لوگو سفید شده تا روی مشکی دیده شود |
| `madfix-logo.svg` | نسخه وکتور شفاف با رنگ‌های اصلی برای استفاده در سایت، چاپ و طراحی |

## آیکون‌های سایت

اسکریپت این فایل‌ها را هم می‌سازد:

- `public/icon.png` — آیکون ۵۱۲×۵۱۲
- `public/icon-192.png` — آیکون ۱۹۲×۱۹۲
- `public/apple-icon.png` — آیکون ۱۸۰×۱۸۰ برای iOS
- `src/app/icon.png` — آیکون خودکار Next.js

## چرا حجم فایل‌ها کم است؟

چون لوگو فقط دو رنگ تخت دارد و به‌صورت وکتور رندر شده، PNG با فشرده‌سازی بدون افت کیفیت ذخیره می‌شود. حجم کم به معنی کیفیت کم نیست؛ رزولوشن واقعی فایل **4096×4096** است و در هر اندازه‌ای تیز می‌ماند.

## ساخت مجدد

```bash
npm install --no-save sharp @neplex/vectorizer
node scripts/generate-brand-assets.mjs
```

اسکریپت این مراحل را انجام می‌دهد:

1. لوگوی اصلی را trim می‌کند.
2. دو ماسک سرمه‌ای و نارنجی می‌سازد.
3. با VTracer هر ماسک را به مسیر برداری تبدیل می‌کند.
4. مسیرها را ترکیب و در ابعاد 4096×4096 روی پس‌زمینه سفید و مشکی رندر می‌کند.
